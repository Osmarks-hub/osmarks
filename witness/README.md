# Witness copy of the public log

`key.json` and `log.json` are daily copies of https://osmarks.marks-90a.workers.dev/key and /log, made by `.github/workflows/witness.yml` after the open verifier checked every signature. The git history of this folder is the independent record of what the log said, and when.

Do not edit these files by hand, except to record an announced key change (see `spec/keys.md`).
